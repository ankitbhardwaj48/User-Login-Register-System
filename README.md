# User-Login-Register-System# 🔐 User Login & Registration System

A full-stack web-based authentication system that provides secure user registration, login, authentication, and protected dashboard access.

This project demonstrates how a frontend application communicates with a Node.js/Express backend and MongoDB database to manage users securely.

## 🚀 Features

- 📝 User Registration
- 🔑 Secure User Login
- 🔒 Password Hashing using bcrypt
- 🎫 JWT-based Authentication
- 🛡️ Protected Dashboard
- 🚪 Secure Logout
- 📧 Email Validation
- ⚠️ Form Validation & Error Handling
- 📱 Responsive Design
- 🗄️ MongoDB Database Integration
- 🔌 REST API

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

### Security
- bcrypt
- JSON Web Token (JWT)
- dotenv

## 🔄 Authentication Flow

User → Registration → Backend API → Password Hashing → MongoDB

User → Login → Backend → Verify Password → JWT → Dashboard

## 🎯 Project Objective

The main objective of this project is to understand and implement a complete user authentication system while learning frontend-backend communication, REST APIs, database integration, password security, and JWT authentication.
